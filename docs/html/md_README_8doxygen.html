PmgBatteryCharger Middleware Library 1.0

Overview

The PMG Battery Charger is ModusToolbox middleware for a USB-C battery charger using a buck-boost power stage. It provides charger policy, battery monitoring, power-stage control, and hardware protection support.

Features

  • Sink-mode charging with pre-charge, normal-charge, full-charge, and optional top-off operation
  • Source-mode operation with battery discharge monitoring
  • Charger state machine for initialization, soft-start, charging, shutdown, cooldown, and source operation
  • ADC measurement of battery voltage, input/output current, voltage rails, and temperature sensors
  • PWM control of the buck-boost power stage
  • Battery OVP, UVP, OCP, OTP, timeout, thermal, and buck-boost error handling
  • Input/output FET, buck-boost enable/reset, rectifier, and discharge control
  • Optional UART debug output

Quick Start

  1. Add the PMG Battery Charger source and header files to a ModusToolbox application with the required PDStack, PDUtils, USBPD, and device PDL dependencies.
  2. Populate a cy_stc_battery_charger_cfg_t structure with the battery cell count, voltage and current limits, timeout settings, thermal thresholds, and post-charge action.
  3. Initialize the middleware with Cy_App_Pmg_Init() and initialize the board hardware with Cy_PmgChg_HW_Init().
  4. Forward PD notifications to Cy_App_Pmg_PdEventHandler() and call Cy_App_Pmg_Task() from the application processing loop.
  5. Use Cy_App_Pmg_Charging_Disable() to stop charging when required. The current status and measurements are available through get_battery_charging_context().

See the API Reference Guide for the generated API documentation.
