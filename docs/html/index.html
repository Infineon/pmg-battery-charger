PmgBatteryCharger Middleware Library

The PMG Battery Charger is ModusToolbox asset middleware for a USB-C battery charger built around a buck-boost power stage. It provides charger policy, battery monitoring, power-stage control, and hardware protection support.

Features

  • Sink-mode charging with pre-charge, normal-charge, full-charge, and configurable top-off behavior.
  • Source-mode operation with battery discharge monitoring.
  • ADC measurement of battery voltage, input/output current, voltage rails, and battery temperature
  • PWM control of the buck-boost voltage/current setting.
  • Battery OVP, UVP, OCP, OTP, timeout, thermal, and buck-boost error flag handling.
  • Input/output FET, buck-boost enable/reset, rectifier, and discharge control.
  • Optional UART debug output and LED status indication.

Public API

Include cy_pmg_charger.h for charger data types and application API, and cy_pmg_charger_hw.h for hardware control and measurement APIs. The application normally calls Cy_App_Pmg_Init() once, forwards PD notifications through Cy_App_Pmg_PdEventHandler(), and calls Cy_App_Pmg_Task() from its main processing loop. Use Cy_App_Pmg_Charging_Disable() to stop charging and get_battery_charging_context() to inspect status and measurements.

Integration

  1. Add the PMG Battery Charger sources and required PDStack, PDUtils, USBPD, and device PDL dependencies.
  2. Populate a cy_stc_battery_charger_cfg_t with cell count, voltage and current limits, timeout behavior, thermal thresholds, and post-charge action. Call Cy_App_Pmg_Init() with the PDStack context and configuration. Initialize board hardware with Cy_PmgChg_HW_Init(). Forward PD events to Cy_App_Pmg_PdEventHandler() and call Cy_App_Pmg_Task() regularly.

Charger states

The pmg_state_t state machine includes initialization and buck-boost setup, pre-charge, normal charge, full charge, top-off, shutdown, cooldown, and source mode. Transitions are driven by PD events, measurements, timers, and hardware error flags.

Configuration defaults

Compile-time defaults in cy_pmg_charger.h include 50 percent multiplicative current reduction between charge cycles, 100 ms sink LED indication, 500 ms source LED indication, a 100 ms battery-monitor task period, and a 1 second current-reduction settling delay. Hardware defaults include a PWM period of 3990 counts, a 9 mOhm input sense resistor, a 15 mOhm output sense resistor, and a 100 kOhm NTC1 at 25 degrees C.
